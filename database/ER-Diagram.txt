+==========================================================================================================================+
|                                         RELATIONSHIP SUMMARY                                                             |
+==========================================================================================================================+
|                                                                                                                          |
|  1.  users (1) --- (1) students         : One user has exactly one student profile                                       |
|  2.  users (1) --- (1) admins           : One user has exactly one admin profile                                         |
|  3.  users (1) --- (1) wardens          : One user has exactly one warden profile                                        |
|  4.  hostel_blocks (1) --- (*) rooms    : One block contains many rooms                                                  |
|  5.  rooms (1) --- (*) students         : One room can house many students (up to capacity)                              |
|  6.  hostel_blocks (1) --- (*) wardens  : One block can have many wardens assigned                                       |
|  7.  students (1) --- (*) leave_requests: One student can submit many leave requests                                     |
|  8.  students (1) --- (*) complaints    : One student can file many complaints                                           |
|  9.  students (1) --- (*) mess_feedback : One student can submit many mess feedback entries                              |
| 10.  students (1) --- (*) lost_and_found: One student can report many lost/found items                                   |
| 11.  students (1) --- (*) marketplace   : One student can list many items for sale                                        |
|                                                                                                                          |

+==========================================================================================================================+
|                                            DATABASE CONSTRAINTS                                                          |
+==========================================================================================================================+
|                                                                                                                          |
|  TABLE              CONSTRAINT             TYPE            DETAILS                                                       |
| ------------------- ---------------------- --------------- ------------------------------------------------------------ |
|  users              idx_users_email        INDEX           Fast lookup by email for login                                 |
|  users              idx_users_role         INDEX           Filter users by role (ADMIN/WARDEN/STUDENT)                    |
|  users              email                  UNIQUE          No two users can have the same email                           |
|  hostel_blocks      code                   UNIQUE          Block code must be unique (A-BLOCK, B-BLOCK, etc.)             |
|  rooms              uk_room_block          UNIQUE          Room number must be unique within a block                      |
|  rooms              idx_rooms_status       INDEX           Filter rooms by availability status                            |
|  rooms              idx_rooms_block        INDEX           Find all rooms belonging to a block                            |
|  students           user_id                UNIQUE          One user maps to one student profile                           |
|  students           enrollment_no          UNIQUE          Each student has a unique enrollment number                    |
|  students           idx_students_room      INDEX           Find all students in a room                                    |
|  admins             user_id                UNIQUE          One user maps to one admin profile                              |
|  wardens            user_id                UNIQUE          One user maps to one warden profile                             |
|  leave_requests     idx_leaves_student     INDEX           Find leave requests by student ID                              |
|  leave_requests     idx_leaves_status      INDEX           Filter leave requests by status                                |
|  complaints         idx_complaints_student INDEX           Find complaints by student ID                                  |
|  complaints         idx_complaints_status  INDEX           Filter complaints by status                                    |
|  notices            idx_notices_role       INDEX           Filter notices by target role (ALL/STUDENT/WARDEN)               |
|  mess_feedback      idx_feedback_student   INDEX           Find feedback entries by student ID                            |
|  mess_feedback      idx_feedback_date      INDEX           Filter feedback by date                                        |
|  lost_and_found     idx_lf_status          INDEX           Filter items by status (LOST/FOUND/RESOLVED)                    |
|  lost_and_found     idx_lf_category        INDEX           Filter items by category                                       |
|  marketplace_items  idx_market_status      INDEX           Filter items by status (AVAILABLE/SOLD)                        |
|  marketplace_items  idx_market_category    INDEX           Filter items by category                                       |
|  marketplace_items  idx_market_seller      INDEX           Find items listed by a specific seller                          |
|                                                                                                                          |
|  CASCADE DELETES:                                                                                                         |
|    DELETE FROM hostel_blocks --> CASCADE deletes all rooms in that block                                                  |
|    DELETE FROM users         --> CASCADE deletes linked profile (students/admins/wardens)                                 |
|    DELETE FROM students      --> CASCADE deletes leave_requests, complaints, mess_feedback,                                |
|                                  lost_and_found, marketplace_items for that student                                       |
|                                                                                                                          |
|  SET NULL ON DELETE:                                                                                                      |
|    DELETE FROM rooms         --> Sets room_id = NULL in students table                                                     |
|    DELETE FROM hostel_blocks --> Sets block_id = NULL in wardens table                                                     |
|    DELETE FROM students      --> Sets reported_by_id = NULL in lost_and_found table                                        |
|                                                                                                                          |
